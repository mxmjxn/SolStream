What will happen

The installer will:

  1. Install NVIDIA driver (Secure-Boot aware) and required libraries
  2. Generate a synthetic 1440p120 EDID and update GRUB so a virtual monitor appears on DP-1
  3. Build gamescope + wayland 1.23 from source (~10 minutes)
  4. Install Steam, Sunshine, PipeWire and the supporting wrapper script
  5. (Optional) Set up WireGuard via wg-easy for remote streaming

You'll need to reboot once after step 2. The wizard will tell you when.
