Next steps

  1. Open the Sunshine UI at the URL above. Set an admin username and password. Your browser will warn about a self-signed certificate — that's expected; proceed past it.
  2. Install a Moonlight client on the device you want to stream to. Recommended clients: NVIDIA Shield TV, Apple TV 4K, any PC. Get it at moonlight-stream.org.
  3. Pair: in Moonlight, add this host (LAN IP above); Moonlight shows a PIN; enter the PIN in the Sunshine UI's "PIN" tab.
  4. Launch "Steam Big Picture" from Moonlight to start streaming.

First-launch: Steam will need to download its runtime (~500 MB) on the host. This happens automatically — give it a couple of minutes after the first stream connects.

Diagnostics

From an SSH session on the host: solstream status, solstream doctor, or solstream metrics 60 during a stream.
